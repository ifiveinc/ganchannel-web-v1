# サークル情報（circle-info）仕様検討シート【記入用】

このファイルは、[requirements.md](./requirements.md) と [spec.md](./spec.md) を作成するための**インプット記入シート**です。
記入が終わったら、その内容をもとに要件定義書・仕様書を作成します。

## 記入のしかた

- `回答:` の右側に書いてください。箇条書き・話し言葉でOKです
- 選択肢は `[ ]` を `[x]` にしてください（複数選択可の設問はその旨を記載）
- **分からない・まだ決まっていない項目は `未定` と書いてください**。空欄のままだと「記入漏れ」なのか「未定」なのか判断できません
- 「★必須」の設問が埋まらないと仕様書が書けません。それ以外は後追いでも進められます

### Q2-2 ★必須　そのユーザーは、どんな場面でこの画面を開きますか？

<!-- 例:「入学式後の新歓期に、スマホで気になるサークルを探すとき」など。
     時期・場所・端末が分かると設計しやすいです -->

回答:
- 新入生→入学後にサークルや学内カンパニーを探すとき
- 在学生→体を動かすために運動系のサークルを探すとき、新しくできた趣味のサークルを学内で探したいとき、学内カンパニーなどの学生向けのプログラムに参加したいとき
- サークル運営側→サークルなどの団体を立ち上げたとき、もしくはサークルオリエンテーション・文化祭・オープンキャンパスで人を募集したいとき

### Q2-3　ユーザーは何ができれば満足ですか？（優先度の高い順に）

<!-- 例: 1. 全サークルをざっと眺められる 2. ジャンルで絞れる 3. 連絡先が分かる -->

回答:
1.自分の中で探したいサークルを見つけられる
2.自分の中で探したいサークルの情報を知れる
3.機能全体が使いやすい
